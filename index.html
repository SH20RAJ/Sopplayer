Engineered for Modern Web Developers

Everything you need for an accessible, robust media experience in under 40 KB.

Zero Runtime Dependencies

Pure, framework-agnostic JavaScript. No bulky third-party libraries required. Weighs under 40 KB minified & gzipped.

WCAG 2.1 AA Accessibility

Built-in keyboard navigation, visible focus indicators, ARIA slider semantics, screen reader live announcements, and reduced motion support.

CSS Custom Properties Theming

Fully customizable design system. Ships with 7 polished skins (Default, Flamingo, Forest, City, Sea, Fantasy, Minimal) or define your own.

Complete Keyboard Shortcuts

Operate playback, seeking, volume, subtitles, and fullscreen effortlessly via Space, K, arrows, J/L, M, F, P, C, and numeric keys.

Picture-in-Picture & Fullscreen

Cross-browser fullscreen and floating Picture-in-Picture API abstraction with smooth state transitions.

100% Backwards Compatible

Drop-in replacement for existing Video.js and v1 integrations. Preserves historical CDN URLs, data-setup attributes, and public APIs.

Quickstart Installation

Choose your preferred integration method.

<!-- 1. Include Versioned Sopplayer Assets (Production Stable) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/SH20RAJ/Sopplayer@v2.0.0/dist/sopplayer.min.css">
<script src="https://cdn.jsdelivr.net/gh/SH20RAJ/Sopplayer@v2.0.0/dist/sopplayer.min.js"></script>

<!-- 2. Add Video Element -->
<video id="player" poster="poster.jpg" preload="metadata">
  <source src="video.mp4" type="video/mp4">
</video>

<!-- 3. Initialize -->
<script>
  const player = new Sopplayer('#player', {
    theme: 'default'
  });
</script>
