Fullscreen & Picture-in-Picture

Supports standardized Fullscreen API with vendor fallbacks and Picture-in-Picture windowing.

Programmatic Control

Trigger Fullscreen or PiP programmatically via the player instance:

// Toggle Fullscreen
player.toggleFullscreen();

// Toggle Picture-in-Picture
player.togglePip();

// Listen to changes
player.on('fullscreenchange', (isFullscreen) => {
  console.log('Fullscreen:', isFullscreen);
});

player.on('pipchange', (isPip) => {
  console.log('Picture-in-Picture:', isPip);
});
